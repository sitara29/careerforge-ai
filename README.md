# CareerForge AI

AI-inspired interview readiness assessment platform for students and job seekers.

## Features
- Role-based readiness scoring
- Recruiter simulation feedback
- Interview ambush predictor
- Hiring probability by company tier
- Missing skills analysis
- 7-day action roadmap
- Downloadable assessment report

## Tech Stack
- React
- TypeScript
- Tailwind CSS
- Lovable
- Vite
